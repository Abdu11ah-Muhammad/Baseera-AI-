#  Baseera — بصيرة

**Baseera** is an AI-powered Arabic Islamic chatbot designed to help users ask questions about Islam and receive clear, contextual, and source-based answers.

The project focuses on making Islamic knowledge easier to access while emphasizing reliable references from the **Quran and Sunnah**.

##  Features

*  Fully Arabic conversational experience
*  AI-powered question answering
*  Quran and Sunnah-based responses
*  Source and citation references
*  Context-aware conversations
*  Dark Mode
*  Responsive design for desktop and mobile
*  Follow-up questions within the same conversation
*  Simple and user-friendly interface

##  Project Goal

The goal of Baseera is to provide a simple and modern platform where users can ask Islamic questions naturally and receive informative answers supported by reliable sources.

> **Note:** Baseera is an educational and informational project and should not replace qualified scholars or official religious authorities, especially for personal fatwas or sensitive religious matters.

##  Technologies

* Artificial Intelligence
* Arabic Natural Language Processing
* Modern Web Technologies
* GitHub
* Google AI Studio

##  Project Status

 **Active Development**

The project is continuously being improved to enhance answer accuracy, source verification, user experience, and citation quality.
